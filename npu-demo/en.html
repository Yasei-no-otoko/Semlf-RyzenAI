What this display means and does not mean

Conditional probabilities. Direct scores are restricted to the displayed options. They are not calibrated confidence.

NPU configuration. This uses AMD’s official model configuration, including CPU host and official prefill/LM-head CPU components. No GPU offload is configured; this does not claim every operator runs on the NPU.

No quality claim. This page reports timing and output from this run. It does not transfer Qwen3.5 or Jev quality results to Qwen3.

Research UI. Input is sent to the local SemIf API on this PC. This is not the official Jev binary or network API.
